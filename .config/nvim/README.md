# Neovim

## Setup

### Windows

1. Choose a package (nvim-winXX.zip) from the releases page.
2. Unzip the package. Any location is fine, administrator privileges are not required.
    - $VIMRUNTIME will be set to that location automatically.
3. Run nvim.exe from a terminal.
4. (Optional) Add the bin folder (e.g. C:/Program Files/nvim/bin) to your PATH. This makes it easy to run nvim from any directory.

### macOS / OS X

Homebrew on macOS or Linux

```bash
brew install neovim
```

Place the config files in `~/.config/nvim/`.
